# 本月生花 V2

以使用者提供的第一版 HTML/CSS/JS 為基礎，新增五區：生日花卡彈窗、地形色塊地圖、無會員花友投稿、個人收藏庫、拍貼機連結。

## 本機預覽

用 VS Code Live Server 或 `python -m http.server 8000` 開啟網站。生日花、花卡、地圖、收藏、拍貼連結可在純靜態模式使用；公開社群在尚未部署後端時會顯示未連線，不會假裝投稿成功。

## 上線步驟

1. 建立 Supabase 專案，在 SQL Editor 執行 `schema.sql`。此腳本建立 `posts` 與私有圖片儲存桶。請確認儲存桶沒有對外開放匿名讀寫權限。
2. 建立 Cloudflare Turnstile 網站，將 **site key** 寫入 `config.js` 的 `turnstileSiteKey`。將 **secret key** 僅設定在 Vercel 環境變數。
3. 將此資料夾上傳 GitHub，Vercel 匯入專案並安裝 `package.json` 依賴。設定 `.env.example` 列出的四個 Vercel 環境變數。切勿將真正的密鑰放入 GitHub 或前端程式。
4. 部署後打開 `/admin.html`，輸入 `ADMIN_API_TOKEN` 載入待審投稿，選擇核准或拒絕。這是原型管理頁，正式公開運營建議加入獨立管理者身分驗證、操作日誌與額外的防暴力嘗試限制。
5. 將拍貼機 URL `https://blooming-taiwan-nine.vercel.app/` 保留於第 5 區。可自行替換展示圖。

## 安全與功能限制

- 投稿必填：照片、遊玩月份、花卉品種、拍攝地點、分享者暱稱、照片授權同意；花旅心得選填。
- 所有投稿先存 `pending`，公開列表僅回傳 `approved`。照片儲存在私有儲存桶，透過限時簽名連結顯示。
- 前後端均限制圖片類型與 5MB；Turnstile 為必要條件。大規模公開前仍需加上 IP/裝置速率限制、圖片內容審核與個資/刪除機制。
- `admin.html` 使用單一管理 API 金鑰，只適合小型畢業專題原型，不應視為完整生產級管理系統。
- 地圖目前是 **色塊地形示意**，山脈與標記位置為近似圖示，不是精確 GIS。景點為初步示範資料，尚未逐點驗證最新開放狀況與花況。
- 花卡 PNG 目前支援背景色、文字、可拖曳符號貼紙；花卉主視覺暫為符號佔位，之後可換成你自己的十二張花卉插畫。這不是完整 Figma 式圖層編輯器。
- 個人收藏使用 localStorage，支援 JSON 匯出/匯入；跨裝置不會自動同步。
